# 变更：项目一律直连，不再读系统代理

**日期**：2026-09-17
**起因**：「我不想项目用代理」

---

## 一、变更

`make_session` 里设 `trust_env = False`，**requests 不再读系统的
`http_proxy` / `https_proxy`**。代理只有一个入口：显式 `--proxy`
（WebUI 则是 `COMIC_PROXY`）。

这么定的依据在上一轮已经查实：本项目抓的都是华语区站点，走翻墙代理常常反而
不通——manhuagui 实测走本地代理 `ReadTimeout`，直连 0.7 秒就 200。

实际效果：开着 v2ray 之类也不会影响本项目抓取。

## 二、顺带删掉两处多余设计

全局默认直连之后，上一轮为解决同一问题加的两个东西就没有存在意义了：

| 删掉的 | 原本作用 | 为什么多余 |
|---|---|---|
| `Site.prefer_direct` | 让站点声明「我要直连」 | 现在所有站点都直连 |
| `--no-proxy` | 强制忽略环境代理 | 现在是默认行为 |

一个配置项如果永远等于默认值，它就只是噪音。删掉后 `make_session` 回到两个参数。

## 三、错误提示同步改口径

```
网络错误: ConnectionError
连不上站点。本项目一律直连（不读系统的 http_proxy/https_proxy）；
如果这个站确实需要代理，显式加 --proxy http://…
```

probe 也改成只在**真的走了代理**时才标注（`(经代理 http://…)`），
直连是常态就不必每次都说。
